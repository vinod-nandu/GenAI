# Week 2 | Day 1 – Minutes of Meeting

## 📅 Topics Covered

### 1. Prompt Engineering
- Introduction to **Prompt Engineering**.
- Understanding the difference between:
  - **System Prompt**
  - **User Prompt**

### 2. RTCFR Prompting Framework
- Introduction to the **RTCFR Prompting Framework**:
  - **R** – Role
  - **T** – Task
  - **C** – Context
  - **F** – Few-Shots
  - **R** – Response
- RTCFR framework demonstration.
- Prompt creation guidelines using the RTCFR framework.

### 3. Prompting Techniques
- Prompt tricks and best practices.
- **Reverse Prompting**.
- **Prompt Chaining**.
- Introduction to **Advanced Prompting** techniques.

### 4. Prompt Keywords
- Understanding important keywords commonly used in prompting.
- Review of the **Prompting Keywords Reference PDF**.

### 5. Prompt Injection
- Introduction to **Prompt Injection**.
- Understanding how prompt injection can affect **Large Language Models (LLMs)**.
- Basic awareness of prompt injection risks.

### 6. Prompt Practice
- **Prompt Engineering Exam**.
- **RTCFR Assignment** details and expectations.

###🎯 Learning Outcome

By the end of Week 2 – Day 1, learners should be able to:

- Understand the fundamentals of Prompt Engineering.
- Differentiate between System Prompts and User Prompts.
- Create structured prompts using the RTCFR framework.
- Apply basic and advanced prompting techniques.
- Understand commonly used prompt keywords.
- Recognize the concept and potential impact of Prompt Injection.
- Practice prompt creation and prepare for the RTCFR assignment and exam.
