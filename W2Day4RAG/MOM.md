Day 4 – Introduction to RAG

1. Introduction to RAG – Understanding Retrieval-Augmented Generation and how external knowledge is provided to an LLM.
2. Types of RAG – Overview of different approaches to improve retrieval and response quality.
3. Self RAG – Understanding how the model can evaluate and improve its own retrieved information.
4. Corrective RAG – Learning how incorrect or poor retrieval results can be identified and corrected.
5. Fusion RAG – Understanding how results from multiple retrieval approaches can be combined.
6. BM25 + ReRank – Introduction to keyword-based retrieval using BM25 and improving results using re-ranking.
7. RAG Demo – Practical demonstration of a basic RAG pipeline.
8. RAG with LangSmith – Using LangSmith to trace and monitor the RAG workflow.
9. RAG Live Assignment – Hands-on implementation of a RAG application.
10. RAG Assignment Details & Resources – Assignment requirements and learning resources were discussed.
